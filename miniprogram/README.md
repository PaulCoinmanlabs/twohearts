# 两颗心 · 微信小程序

微信原生小程序的起始工程。当前只有中性欢迎页，用于确认项目可以在开发者工具中打开；微信登录、设备连接、双人确认和互动尚未实现。

## 本地运行

1. 安装并打开微信开发者工具，选择「导入项目」。
2. 选择本目录。`project.config.json` 中的 `touristappid` 仅供体验和本地预览；需要真实微信能力时，请在开发者工具中使用自己的小程序 AppID。
3. 编译并在模拟器中查看欢迎页。

无需安装 npm 依赖。`project.private.config.json` 是开发者工具的个人配置，已加入忽略列表；请不要把密钥、证书或真实用户数据提交到 Git。

## 目录

```text
app.js / app.json / app.wxss  全局入口与配置
pages/index/                 中性欢迎页
project.config.json          开发者工具项目配置
sitemap.json                 页面索引配置
```

## 方向与边界

- 登录和连接前采用中性视觉，识别玩偶后再切换角色主题。
- 计划由双方主动确认微信账号间的专属连接；微信账号不等同于经核验的唯一自然人。
- 拥抱感应、设备声音、离线互动及服务端接口均需后续设计和实现，当前页面没有模拟其已经可用。
- 交互原型和需求文档位于当前工程同级的「需求+原型+UI效果图」目录。
