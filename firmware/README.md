# 两颗心｜硬件端

此目录是情侣玩偶硬件端的独立项目，用于后续维护设备固件、硬件接口和测试资料，并可单独上传到 Git 仓库。

## 当前状态

项目目前只建立目录与需求记录，**尚未选定芯片、开发板、联网方式或固件框架，也没有可编译或可烧录的固件**。现有 HTML 原型中的拥抱感应、灯光、声音、联网和送达状态均为交互模拟，不代表设备已具备这些能力。

## 目录

```text
firmware/
├── src/        # 后续放置固件源码
├── include/    # 后续放置固件公共头文件
├── interfaces/ # 硬件及服务通信接口的约定和待确认问题
├── tests/      # 测试计划与后续测试代码
└── docs/       # 硬件方案和设计决策
```

## 产品方向

- 两只玩偶由各自的微信账号连接，双方确认后建立专属关系；账号关系由服务端管理，设备更换不应改变原关系。
- 计划探索通过拥抱触发灯光和声音，并支持声音关闭、免打扰及离线情况下的体验；具体感应方式、音效和设备能力尚待确认。
- 设备连接、互动信号和执行回执等能力需在软硬件方案确定后共同设计，不能将模拟效果视为真实送达。

## 待确定

1. 芯片与开发板、开发语言和构建工具。
2. 设备联网方式、配网流程及与后台的通信协议。
3. 拥抱检测方式、扬声器、灯光、电源、续航和成本。
4. 设备身份、绑定、维修换机、掉线重连及更新方式。
5. 声音开关、免打扰、离线消息及设备执行回执的具体规则。

更完整的产品说明位于当前工作区的「需求+原型+UI效果图」目录。硬件选型确定后，再补充构建、烧录、调试与真机测试步骤。请勿将设备密钥、网络凭据或用户数据提交到仓库。
