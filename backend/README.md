# 两颗心 · 后台服务

后台服务的独立项目目录，供后续单独上传 Git。当前仅提供不依赖第三方包的启动框架和健康检查，尚未实现微信登录、设备连接、双人确认、唯一关系、声音互动或数据存储。

## 本地运行

需要 Node.js 18 或更新版本。在本目录运行：

```powershell
npm start
```

访问 `http://127.0.0.1:3000/health`，返回 `{"status":"ok"}` 表示服务已启动。默认只监听本机。需要其他端口时，可在 PowerShell 中先设置 `$env:PORT = '3001'` 再启动。

## 后续开发

正式接口、数据库、微信账号标识与权限、设备通信、安全策略以及部署方式需要结合小程序和硬件方案共同确定。唯一连接仅以微信账号为范围，不能宣称已验证真实自然人的唯一性；本项目目前不做持久化或业务限制。

不要把微信密钥、数据库密码、生产环境配置或其他敏感信息提交到 Git；本地 `.env` 文件已加入忽略列表。上传前由项目负责人决定仓库地址、可见性和部署方式。
